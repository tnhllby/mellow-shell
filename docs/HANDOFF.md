## Architecture (as built)
- `shell.qml`: per screen — Wallpaper, TopBar, Island, WorkspaceFrame,
  FrameReservation ×3, Dock, ControlCenter, Launcher, WallpaperStudio, Overview (last).
- `core/`: Config (static settings), Theme (tokens; `Theme.color` = ThemeColors bound
  to ThemeState), ColorScheme/ThemeColors (generated by `tools/gen-palette.py`),
  ThemeState (`~/.local/state/mellow/theme.json`: mode + optional generated scheme),
  Typography, Motion, ShellState (which monitor shows CC/Dock/Island/Studio/Launcher/
  Overview; full-screen modes are exclusive), Icons, Paths, ColorUtil (WCAG).
- `integrations/hyprland/HyprlandService.qml`: the only Hyprland access point;
  `dispatch(classic, lua)` chooses syntax via `Hyprland.usingLua`; focus/close/move
  window (`hl.dsp.window.move({ workspace, follow = false, window })`),
  `hasRealFullscreen` (Hyprland's `hasfullscreen` also covers maximize).
- `services/`: Media, SystemStats, Audio, Network, Bluetooth, Power, Brightness
  (backlight via logind `SetBrightness`; external monitors via `ddcutil`, per monitor),
  Wallpaper (matugen schemes, per-monitor wallpapers, one-step revert), App (search,
  launch, launch counts, window → desktop entry).
- `modules/`: TopBar, Island, Frame, Dock, ControlCenter (Main/Wi-Fi/Bluetooth pages),
  Background, WallpaperStudio, Launcher, Overview, Shortcuts (GlobalShortcuts appid
  `mellow` + IpcHandler target `mellow`).
- Keybindings (until M6): see docs/RUNNING.md; launcher uses
  `bindr = SUPER, SUPER_L, global, mellow:launcher` and acts on the **released** event.

## Hard-won lessons (do not regress)
- Interactive surfaces are **always-mapped layer surfaces** whose `mask` is the card
  while open and empty otherwise; never xdg-popups (Hyprland's focus grab treats clicks
  inside a layer-shell popup as outside clicks) and never toggle `visible` together
  with a focus grab.
- Quickshell service singletons (Pipewire, UPower, Networking, Bluetooth) only
  initialise when referenced in bindings at startup.
- QML's JS has no `Array.flatMap`; properties named `onX` are signal handlers (Material
  `onX` roles are `contentX`); `left`/`top` are final on Items; a `readonly` property
  cannot be animated; setting `exclusiveZone` overrides `ExclusionMode.Ignore`.
- Hyprland applies exclusive zones in layer and creation order; the bar draws the inner
  fillets itself so they follow the bar if something pushes it down.
- Toggling a PanelWindow's `visible` from a property that depends on `screen` loops.
- `ScreencopyView.captureFrame()` only after the first capture (`hasContent`).
- A release bind only sends the global shortcut's `released` signal.
- Verify every Quickshell type/property against the installed qmltypes in
  `/usr/lib/qt6/qml/Quickshell/`; Hyprland Lua API stubs are in
  `/usr/share/hypr/stubs/hl.meta.lua`.
