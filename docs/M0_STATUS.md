# M0 Status

## Implemented
- Project bootstrap (`shell.qml`, `qs.*` module layout) and install/uninstall scripts.
- `core/`: `Config` (static settings), `Theme` (semantic colours, shape, spacing, state
  layers, focus ring), `ColorScheme` (Material 3 tonal scheme from seed `#5E8C7A`,
  generated by `tools/gen-palette.py`), `Typography` (M3 type roles, font fallback),
  `Motion` (durations, M3 easing, reduced-motion).
- `components/`: `Surface`, `StateLayer`, `FocusRing`, `MText`, `MaterialIcon`, `IconButton`.
- `integrations/hyprland/HyprlandService`: the only place that touches Hyprland; event-driven.
- Top panel per monitor: workspace strip (top-left), Island compact ambient state (time/date),
  Control Center trigger with an M0 placeholder popup.
- Left-edge auto-hiding Dock with pinned apps from `Config.dock.pinned`.
- Persistent workspace frame: visual surface with an empty input region, plus invisible
  exclusive-zone strips so windows tile inside it. Hidden while the monitor's active
  workspace has a fullscreen window (`Config.frame.fullscreenPolicy`).

## Test-machine feedback (2026-11-16)
- Dock hid while the pointer rested on the screen edge. Fixed by switching to a single
  hover zone whose input region grows from the edge strip to the whole dock column
  (needs re-test on the test machine).
- Frame thinned to 4 px; bar and frame now share rounded outer screen corners and
  rounded inner fillets around the workspace (`Theme.chromeShape`).

## Verified on the development host (alongside ii)
- Shell loads with no QML errors or warnings in the log.
- All surfaces are created on both monitors (`hyprctl layers`), with the expected geometry.
- Reserved space becomes `[6, top, 6, 6]` (frame + panel) and returns to ii's values after stopping.
- Panel zones, workspace strip (per-monitor, focused vs. unfocused styling), Island,
  Control Center popup and frame all render (screenshots taken).
- The frame received no pointer hover when the cursor was warped onto it (empty input region).
- `install.sh --dry-run` against temporary XDG directories.

## Unverified (needs the test machine — see docs/RUNNING.md checklist)
- Dock reveal on edge hover (cursor warps via `hyprctl` did not trigger it; may be a
  warp limitation or a bug).
- Dock app launch, Control Center open/close by pointer and keyboard.
- Fullscreen frame hiding.
- Workspace switching by click/scroll (not exercised on the host to avoid disturbing the live session).
- Monitor hot-plug; mixed display scales (host monitors are both scale 1).
- Real `install.sh` run (fonts download, symlink, pacman).

## Known limitations
- Panel and Dock never take keyboard focus (layer `keyboardFocus: None`), so keyboard
  navigation inside them is not possible yet. Keyboard entry points (global shortcuts /
  IPC) are planned for M1; Launcher/Overview keybindings for M4.
- Dock: no running-app indicators or keyboard navigation yet (M4).
- Status indicators in the right zone are intentionally absent until their services exist (M3).
- Theme is static; light mode exists in `ColorScheme` but has no UI toggle; no wallpaper-derived colours (M3/M5).
- Blur is not used; no Hyprland layer rules are installed.
- If another shell runs at the same time, its exclusive zone pushes MELLOW's panel down
  while the frame stays anchored to the screen top, so their edges do not meet.
